# KoPub돋움체 웹폰트 (자체 호스팅)

이 폴더에 KoPub돋움(KoPub Dotum) 파일을 아래 이름으로 넣으면 빌드 시 `site/assets/fonts/`로 복사되고
`@font-face`가 자동 생성됩니다. 파일이 없으면 Noto Sans KR(Google Fonts)로 폴백합니다.

| 파일명 | 굵기 매핑 |
| --- | --- |
| `KoPubDotum-Light.woff2` (또는 .woff/.ttf/.otf) | 300 |
| `KoPubDotum-Medium.woff2` | 400~500 (본문) |
| `KoPubDotum-Bold.woff2` | 600~700 (제목) |

KoPub 서체는 한국출판인회의가 무료 배포하는 폰트이며, 배포 라이선스에 따라 웹폰트 사용이 가능합니다.
사내 승인 폰트 자산(KoPub Dotum Pro)을 우선 사용하고, 라이선스 고지 의무를 확인하세요.
